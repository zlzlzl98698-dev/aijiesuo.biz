# 代理机场选型知识库与专题总览

> **核心结论（Answer-First）**：代理机场是以 Shadowsocks、VLESS、Trojan 或 Hysteria 2 等代理协议为基础，向用户提供跨境节点订阅或专属客户端接入的网络中继服务。选型时不存在“全能且零风险”的单一标准答案，应先明确自身核心诉求（AI 工具、流媒体、轻度办公或低预算备选），再核查传输线路、客户端开放度、单次测速记录与运营稳定性，避免被未经核实的宣传口号误导。

## 什么是代理机场与核心构成

在中文跨境网络语境中，“机场”最早源自早期 Shadowsocks 图标中的纸飞机意象，现指代批量部署海外节点并按流量或周期售卖订阅接入服务的商业平台。一套完整的机场服务通常由以下四部分组成：

1. **接入入口与传输链路**：国内端到海外落地机之间的传输通道，常见分为公网直连、BGP 中转、以及厂商宣称的 IEPL 或 IPLC 专线。不同线路决定了晚高峰拥塞时的丢包率与抖动幅度。
2. **代理传输协议**：客户端与服务端之间的数据封装协议，本站收录的 32 个品牌资料中主要涉及 `Shadowsocks`、`VLESS`、`Trojan`、`Hysteria 2` 与 `AnyTLS`。
3. **订阅分发与客户端体系**：决定用户能否使用开源第三方客户端（如 [Clash Verge Rev](/clients/clash-verge-rev/)、[v2rayN](/clients/v2rayn/)、[Shadowrocket](/clients/shadowrocket/)），还是只能依赖服务商提供的专属客户端。
4. **落地节点与出口 IP 属性**：决定了目标服务（如 [ChatGPT](/ai/chatgpt/)、[Claude](/ai/claude/)、[Gemini](/ai/gemini/)、[Netflix](/ai/netflix/)）是否将其识别为高风控机房 IP 或受限地区。

## 机场评估五大核心维度与数据分级

为防止把厂商推广文案当成客观评测，本站对全部 32 家品牌档案实行五类数据状态标签管理：

| 数据状态标签 | 含义与来源边界 | 本站使用规范 |
| --- | --- | --- |
| `measured` | 保留原始截图的节点测速或流媒体检测记录（如 2026-08-11 批次） | 必须标注测试时间、后端条件与局限，不推导出长期稳定或全部解锁 |
| `vendor` | 品牌官网、面板或宣传文本中的价格、线路、设备数与解锁声明 | 明确标注为官方声明或品牌资料，存在前后文本冲突时同步披露 |
| `commercial` | 优惠码、支付方式、推广链接与商业顺位 | 与研究评分完全隔离，披露利益关系 |
| `editorial` | 基于参数完整度与场景特征的编辑判断 | 说明推理依据，不伪装为实测数据 |
| `unverified` | 历史归档记录（如 2026-08-09 留存）或信息严重缺失条目 | 明确提示待核实缺口，不作为主力推荐依据 |

### 本站机场研究评分（Research Score）构成

本站采用 0–100 分的透明研究评分体系，与商业推广顺位（`commercialRank`）完全独立：

| 评估维度 | 满分权重 | 核查重点 |
| --- | --- | --- |
| 资料完整度 | 30 分 | 套餐表、协议、设备限制、支付方式、官网入口是否齐备 |
| 协议与线路清晰度 | 20 分 | 传输线路类型与协议标注是否明确、实测图与宣传是否一致 |
| 实测证据可用性 | 25 分 | 是否具备可追溯时间戳的测速截图、三网或解锁快照 |
| 套餐与定价弹性 | 15 分 | 是否提供月付试错、年付入门及不限时按量等多元选择 |
| 风险与局限透明度 | 10 分 | 退款边界、数据冲突与已知异常节点是否清晰可查 |

## 局限性与阅读边界

1. 任何测速截图仅反映当时测试节点（例如特定地区运营商后端）到目标节点之间的单次表现，无法覆盖全国所有宽带运营商（电信、联通、移动、广电）的实际路由。
2. 在本站已核查的 32 家品牌资料中，部分品牌的宣传协议（如自称 `VLESS`）与 2026-08-11 实测截图显示的 `Shadowsocks` 存在出入，此类差异均在对应[品牌档案](/brands/)中保留原文冲突记录。
3. 跨境网络环境与风控策略处于动态变化中，任何服务商均无法保证对特定 AI 或流媒体服务的永久可用性。

## 常见问题（FAQ）

### 新手选机场应该先看价格还是先看协议与客户端？
建议先看**客户端开放度**与**计费周期**，再看价格。支持通用第三方订阅且提供月付档位的方案，即使后续线路波动也能低成本迁移；若选择仅支持专属客户端的年付方案，更换工具的隐性成本会更高。

### 本站的“机场推荐”和“机场排行榜”有什么区别？
[综合机场推荐](/airport/recommend/)按具体使用场景（综合实测、轻度入门、多设备不限终端、原生订阅等）提供决策路径；[机场综合榜单](/airport/ranking/)则完整展示 32 家品牌的 `commercialRank` 与 `researchScore` 对照表，并解释二者分离的原因与测速样本边界。

### 为什么部分机场在资料里写了支持某 AI 工具，实际却无法访问？
厂商资料中的“支持”属于 `vendor` 声明，往往只代表部分地区节点或特定时期的可用性。同一机场的香港节点与新加坡、日本、美国节点在 OpenAI、Claude、Gemini 上的风控策略截然不同，实际使用需参考实测快照并在客户端中配置定向分流。
