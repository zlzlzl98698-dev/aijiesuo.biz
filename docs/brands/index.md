# 机场品牌库：32 家品牌档案与数据分级目录

**机场品牌库（`/brands/`）** 是 aijiesuo.biz 面向跨境代理与 AI 服务访问场景的实体资料索引中心。与普通榜单页面不同，本目录不把厂商自述当作客观事实，而是将每一家品牌拆解为**协议、传输线路、客户端兼容模式、套餐梯度、实测证据覆盖度与公开冲突项**六个可核查维度，并在所有卡片与详情页中分离展示 `commercialRank`（商业合作顺位）与 `researchScore`（0–100 研究完整度与证据评分）。

## 数据状态分级图例（Data Status Legend）

阅读任意品牌档案或评测前，请先确认对应字段所属的数据层级。同一品牌的不同维度往往处于不同可信度等级：

| 状态标识 | 中文定义 | 覆盖内容范围 | 阅读与决策边界 |
| --- | --- | --- | --- |
| `measured` | 实测证据 | 2026-08-11 批次（16 家原始 PNG）、2026-07 月份归档截图（微风/无忧链接）、光速云 2026-08-19 MiaoKo 5 张 JPG 截图 | 仅证明截图当次时间点与测试节点下的速度、延迟或流媒体/AI 状态，不自动代表全年稳定性 |
| `vendor` | 品牌资料 | 厂商官网套餐价格、流量周期、线路类型宣称、非晚高峰参考测速表（2026-10-19）、客服与节点地区描述 | 属于服务商单方陈述；若与实测截图（如宣称 VLESS 却实测 Shadowsocks）存在偏差，档案页会直接列出冲突 |
| `commercial` | 商业资料 | 优惠码、折扣幅度、联盟推广链接及佣金披露状态 | 本站所有推广链接统一标注 `nofollow sponsored noopener`，不影响用户支付价格 |
| `unverified` | 待核实 / 缺口 | 缺失官网完整套餐表（如宇宙云、大佬云系）、协议未明（如榴莲云）、仅历史存档（2026-08-09）或仅测速无文字资料（如快狸） | 未经二次核验前不予评分加分，并在对应品牌页底部列出「待补充研究任务」 |

## 评分方法论：为什么 `researchScore` 与 `commercialRank` 必须分离？

在机场评测领域，商业合作排序与技术透明度经常错位。本站采用 **100 分制独立研究评分模型（v1.0）**，专门衡量“用户能在多大程度上核查这家品牌的真实边界”：

1. **资料完整度（30 分）**：是否具备清晰的多周期套餐表、节点覆盖地区、设备连接限制、流量倍率与客服渠道说明。
2. **协议与线路清晰度（20 分）**：是否明确交代代理协议（Shadowsocks / VLESS / Trojan / Hysteria 2 等）与传输架构（IEPL / IPLC / BGP 中转），且不与实测工具显示产生严重冲突。
3. **实测证据可用性（25 分）**：是否拥有可追溯时间戳的测速截图（如 《2026-08-11 节点测速原始图像校验清单》 收录的 16 家，或光速云的三网 + 流媒体/AI 实测图）。
4. **套餐与定价弹性（15 分）**：是否提供按月试错档、年付轻量档或一次性不限时流量包，降低新手沉没成本。
5. **风险与局限透明度（10 分）**：是否坦诚披露无免费试用、特殊商品不退款、AI 解锁受 IP 与地区限制或链接格式异常等问题。

> [!NOTE]
> 以主推品牌 [光速云](/brands/guangsu/) 为例：其 `commercialRank` 为 1，同时因为具备 2020 年起的运营记录、7 档完整套餐、2026-08-11 与 2026-08-19 共 6 张实测截图以及坦诚的风险边界，`researchScore` 达到 92/100。而部分同样排在前列的品牌若缺乏实测截图或套餐表，其研究评分会如实停留在 30–50 区间。
