# 隐形人深度评测：定价偏高且彻底锁端，缺乏实测与一致口径

## 核心结论

- **品牌定位**：隐形人（`Invisible`）主打「企业级 IPLC 专线直连」，提供 9 档完整套餐（含 ¥109 年付、¥24–¥185 月付、¥229–¥1199 一次性包与 ¥680 王者定制版），但**强制仅限自带专属客户端，不提供第三方订阅链接** `[品牌资料 Vendor Claimed]`。
- **突出风险**：32 家品牌中少见的「参考测速表全为空白（`—`）+ 无 2026-08-11 实测截图」品牌，且同时存在**四重内部冲突**（`yxr888` vs `moon80`、入门 100GB vs 144GB、汇总表新增未在正文出现的「1小时修复承诺」、协议未标注）。
- **对比结论**：与同价位、同样不开放订阅的 [闪跃](/reviews/shanyue/) 相比，隐形人多了 3 档一次性流量包但单价偏贵且缺少测速参考表；与 [梯子云](/reviews/tiziyun/) 相比，隐形人在客户端自由度与设备透明度上明显处于下风。

## 一、运营资料与客户群体边界

隐形人自 2024 年起运营 `[品牌资料 Vendor Claimed]`，商业顺位第 27 位，研究评分 `44 / 100`。它的风险与局限透明度得分偏低（`4 / 10`），原因在于资料中既保留了较多厂商自述（「晚高峰零卡顿」「秒开 4K/8K」），又未能提供哪怕一组实测数据去支撑高定价。

- **适合人群**：极度抗拒自行安装配置 Clash/小火箭、愿意完全依赖官方专属客户端且只关注港/台/日/新/美五地的轻度合规或办公尝鲜用户（建议先试单月白银纪元）。

## 三、套餐价格、优惠码冲突与一次性包单价分析

<PlanComparison slug="yinxingren" />

### 1. 入门月付流量与优惠码冲突
- **白银纪元流量冲突**：基础数据行写「24元/月 100GB/月」，而价格表与正文介绍写「¥24/月 144GB/月」。以折后估算，若按 `moon80`（8 折）计算，白银纪元月付可降至 **¥19.2/月**（若为 144GB 则约 ¥0.133/GB；若为 100GB 则约 ¥0.192/GB）。
- **双优惠码冲突**：存在 `yxr888`（折扣未明示）与 `moon80`（8 折，限制未标注）两份记录 `[商业信息 Commercial]`。

### 2. 一次性不限时流量包溢价偏高
隐形人提供了三档一次性流量包，但按每 GB 单价换算明显高于同库其他品牌：
- **隐形人一次性包**：¥229/160GB（**¥1.43/GB**）、¥549/420GB（**¥1.31/GB**）、¥1199/1.0TB（**¥1.20/GB**）。
- **横向对比**：[SOGO 云](/reviews/sogo/) 不限时包为 ¥0.85–¥1.00/GB，[全球云](/reviews/quanqiu/) 为 ¥0.875–¥1.00/GB，而老牌光速云 147 永久包（¥147/247GB）更是仅约 **¥0.595/GB**。除非非常看重隐形人的某个特定生态，否则其不限时包性价比较弱。

## 六、优势、不足与购买建议

### 优势
1. **月付、年付、一次性包与定制档齐全**（9 档选择面广）。
2. **对 Claude 与 TikTok 保留了中性边界**，未在说明中一刀切吹嘘全解锁。

### 不足与风险
1. **零可用测速数字**：参考测速全 `—` 且无实测 PNG，无法判断真实吞吐表现。
2. **强制锁端且设备上限不透明**：不支持 Clash/Shadowrocket，且未标明各档套餐具体可同时在线的设备数量。
3. **四处内部资料冲突**（双码、入门流量、协议缺失、汇总表孤立卖点）。

### 待补充研究任务与购买建议
- **待补充研究任务**：核实 `moon80` 与 `yxr888` 优惠码、白银纪元流量究竟为 100GB 还是 144GB、各档具体设备上限、「1小时修复承诺」条款真伪，并补充专属客户端实测测速。
- **购买建议**：如果希望兼顾客户端新手易用性与通用订阅自由度，更建议先对比 [梯子云评测](/reviews/tiziyun/)；若一定要亲自验证隐形人，务必先用月付 **白银纪元（尝试 `moon80` 8 折）** 确认设备限制与节点可用性，避免直接买高单价一次性流量包或年付。
