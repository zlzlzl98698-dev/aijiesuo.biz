# 榴莲云深度评测：5.6 元档中唯一协议未明，研究评分垫底的客观原因

## 核心结论

- **数据现状**：榴莲云（`liulianyun`）在价格定位上与大佬云、闪电鼠同属「2024 年运营 + IEPL + 年付约 ¥5.6/月（60GB/月）+ 季付及以上 7 折（`ll88`）」组别，但**研究评分仅为 `28 / 100`**，是 32 家品牌中最低的一家。
- **垫底原因**：一方面，它是 5.6 元五家同质品牌中**唯一未明确标注底层协议**的机场；另一方面，推广链接存在域名后直接拼接 `#`、缺少斜杠 `/` 的格式异常，同时完全缺失完整套餐表、节点地区与实测图。
- **选型建议**：除非在官网后台亲自确认了当前下发的协议类型与短周期试错价格，否则同预算下更建议先核查协议清晰的 [大佬云](/reviews/dalaoyun/) 或 [闪电鼠](/reviews/shandianshu/)。

## 一、为什么「协议未明」在评测中是关键硬伤？

榴莲云宣称支持「自研客户端 + 第三方订阅导入」`[品牌资料 Vendor Claimed]`，但却没有写明节点采用哪种代理协议。对于依赖第三方通用客户端的用户，不知道协议会带来三个实际问题：
1. **客户端选型盲区**：如果它采用 Shadowsocks / Trojan，几乎所有老版本和轻量客户端都支持；但如果采用 VLESS-Reality 或 Hysteria 2，就必须确保你的客户端搭载较新的 Mihomo 或 sing-box/Xray 内核（参阅 [代理客户端选型](/clients/)）。
2. **软路由与系统兼容**：老旧路由器固件可能不支持新型 QUIC 或特定传输层协议。
3. **同组对比毫无优势**：同组的 [大佬云](/reviews/dalaoyun/) 与 [闪电鼠](/reviews/shandianshu/) 价位完全相同，却明确标出了 `VLESS`。

## 四、购买风控与待补充研究任务

- **链接格式提醒**：榴莲云推广链接在域名与 `#` 间缺少 `/`（不同于云界线/环球梯的缺少 `#`）。虽然大多数现代浏览器会自动规范化根路径 `/` 并成功跳转，但如果遇到异常，建议检查地址栏路径格式或先核实是否可正常访问注册页面。
- **风控原则**：在缺少协议、月付原价、节点列表和实测表现前，**不建议直接购买年付**（参阅 [购买避坑指南](/risk/buying-guide/)）。
