# 宇宙云（`yuzhou`）评测：有晚间 VLESS 实测截图，但官网资料大面积待核实

**宇宙云（`yuzhou`）** 是全站 32 家品牌里研究结构最特殊的一例——按常理，没有完整官网套餐表的品牌通常也不会有实测图；但宇宙云恰恰相反：**品牌文字档案严重缺水（缺套餐、缺流量、缺节点列表、缺客服信息，研究评分仅 `41/100`），可 `2026-08-11` 测速包里却实打实保留了一张 `21:04:24 CST` 晚高峰 VLESS 实测截图**。本篇评测严格遵循“有一分证据说一分话”原则，绝不靠想象把空白字段填满。

## 1. 核心结论

- **测速证据真有，只是没进品牌正文 `[实测证据 Measured]`**：尽管清单第 397 行写着“暂无可核实实测数据”，但 《2026-08-11 节点测速原始图像校验清单》 明确收录了 `宇宙云-节点测速实测.png`（测试时间 **`2026-08-11 21:04:24 CST` 晚间黄金时段**，协议显示 **`VLESS`**，使用 `主端 4.3.3 (696) / 喵速 4.7.0 (A11-32)` 珠海联通 9Gbps 32 线程测得）。
- **商业与套餐透明度太低**：只知道历史起步价为 `¥96/年`，连这 96 元对应每月多少 GB 流量、有没有月付套餐、是否限设备、用什么客户端（自研 vs 第三方订阅）都处于 **`待核实`**。
- **现阶段决策建议**：在补充到当期官网完整价格截图前，**不建议普通用户盲目下单**，仅可先点进面板确认在售套餐与月付门槛再做判断。

## 2. 品牌背景、运营资料与定位

- **开业年份 / 团队 / 客服 / 支付方式**：均 **`待核实`**（现有历史文本完全未记录上述运营信息）。
- **历史定位线索**：较早期品牌资料仅留下了“**60+ 节点、三网优化、智能负载均衡、VLESS 协议**”四项标签，而汇总表额外写了“IEPL + VLESS + 自研客户端”（但正文第 384 行明确提醒“使用方式待核实，不默认专属客户端或提供订阅链接”）。

## 3. 线路技术、节点地区与协议核对

- **协议一致性**：这是宇宙云少数能互相印证的亮点——较早期文字资料记为 `VLESS`，`2026-08-11 21:04:24 CST` 实测截图同样显示为 **`VLESS`**（与同批次的 `快狸` 一起采用新版 MiaoKo 9Gbps VLESS 界面，而非另外 14 家的 MAI-TEST-BOT Shadowsocks 界面）。
- **节点地区与线路类型**：`待核实`。虽然历史称有“60+ 节点”，但未披露具体覆盖香港、日本、新加坡、美国或台湾的分布比例，也未证实“三网优化”背后是公网中转还是 IEPL 专线。

## 5. 客户端兼容与使用体验

目前无法确认宇宙云究竟是“必须使用自研客户端”还是“支持 Clash Verge Rev / v2rayN / Shadowrocket 通用 VLESS 订阅”。不过既然 `2026-08-11` 使用的喵速（MiaoKo）工具能够直接跑通 VLESS 订阅测速，说明至少在 8 月测试时节点底层是基于标准 VLESS 协议的。

1. **信息黑箱风险**：购买前不知道具体流量额度、不知道月付价格、不知道是否限设备以及客服在哪里，这在消费决策上属于极高不确定性。
2. **同类对比**：如果你看重 **VLESS 协议 + 实测证据**，但同时希望看清全部套餐价格、节点覆盖与退款说明，建议对照已完整披露 50 节点 Vless 测速的 [微风网络评测](/reviews/weifeng/)，或直接选择多维透明的 [光速云评测](/reviews/guangsu/)。

## 9. 待补充研究任务（Research Backlog — 重点补全清单）

由于宇宙云是站内少有的“有晚间 VLESS 实测却缺官网资料”的倒挂案例，后续研究需优先完成以下 5 项核实：

- [ ] **补全官网套餐表**：记录当期在售的全部月付、年付及不限时套餐价格、每月流量与是否支持 1× 倍率。
- [ ] **核实客户端与订阅模式**：确认是否强制下载自研客户端，还是允许提取 VLESS 订阅导入 Clash/v2rayN/小火箭。
- [ ] **确认传输线路与节点分布**：核实汇总表所称“IEPL + 60+ 节点”的真实节点列表（港/台/日/新/美等地区构成）。
- [ ] **核实商业与运营信息**：确认开业年份、支付渠道（支付宝/微信/USDT）、客服入口以及历史优惠码 `YUZHOU553` 是否仍有效。
- [ ] **补充解锁测试**：针对 ChatGPT、Claude、Gemini 与 Netflix/YouTube 完成独立节点解锁检验。

## 10. 购买建议

- **当前结论**：在官网面板价格、流量配额与订阅规则没有明确前，**不建议直接充值购买宇宙云年付套餐**。若你对这张晚高峰 VLESS 测速背景感兴趣，可先点击入口进入官网后台查看最新在售月付方案与面板说明，确认有小额月付且条文清晰后再做轻度试错。
