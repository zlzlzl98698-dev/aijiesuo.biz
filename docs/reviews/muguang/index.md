# 暮光加速（Twilight）深度评测：高商业排位背后的实测空白与核查清单

虽然 **暮光加速（`muguang`，英文名 Twilight）** 在商业合作顺位中排第 2，但按照本站独立研究评分规则，它目前仅获得 **`48/100` 分**（资料完整度 22/30、协议与线路清晰度 8/20、实测证据 **0/25**、套餐弹性 14/15、风险透明度 4/10）。核心原因很明确：它虽给出 9 档月付/年付/不限时定价，却**缺少协议类型、客户端订阅模式、设备并发上限、流量倍率、支付方式以及任何独立测速截图**。本篇严格基于已有档案逐项拆解，绝不拿厂商参考表替代真实评测。

## 1. 核心判断（信息透明度与试错底线）

- **可见优势** `[品牌资料 Vendor Claimed]`：2023 年上线，月付门槛低至 `¥20/月（120GB）`，最高可达 `¥180/月（1500GB）`，另配三档不限时一次性包（150GB / 400GB / 800GB），宣称支持五端全平台、多设备在线及 `7×24` 真人客服。
- **核心硬伤** `[待核实 Pending Verification]`：**0 张独立实测测速截图**，`protocols` 字段完全空白（未说明 SS / Trojan / VLESS / Hy2），`clientMode` 处于 `unverified`（未知是否允许导出第三方 Clash/Shadowrocket 订阅），且存在优惠码与卖点文本前后矛盾。
- **现阶段购买红线**：仅建议把 **¥20 基础版月付** 当作自费试错入口；未亲测前切勿盲买 ¥109 年付或 ¥529 / ¥959 高价不限时包。

## 2. 运营资料、线路模糊点与协议缺口

- **运营与客服** `[品牌资料 Vendor Claimed]`：成立于 2023 年，主打个人与团队跨平台协同，宣称 7×24 真人客服；但支付渠道（支付宝 / 微信 / USDT）原文未列明，多设备具体并发台数上限亦未量化。
- **“BGP 智能调度 + 专线级出口”边界**：不同于光速云、星岛梦明确标注 IEPL/IPLC 物理或内网专线，“专线级出口”属于未界定物理层级的商业术语，可能指 BGP 优化中转，也可能指部分专线出口，无法在无测速包的情况下交叉印证。
- **协议空白与内核匹配风险**：全库多数品牌至少会写明底层协议，而暮光加速协议字段为空。对于打算上 **OpenWrt（OpenClash/PassWall2）** 或写 **Mihomo 分流规则** 的用户，协议与订阅格式不透明意味着购买前无法确认兼容性。

## 4. 客户端与工程接入策略（待核实订阅前提下的两套预案）

由于暮光加速尚未明确 `clientMode`（是否开放标准 Clash/Mihomo 订阅链接），工程落地必须按后台实际权限采取分支方案：

1. **情况 A：若官网后台确认支持 Clash/Mihomo 订阅导出 `[待核实前提]`**
   由于暮光仅覆盖 **香港、台湾、新加坡、日本、美国** 5 个地区且流量倍率未标注，接入 [Clash Verge Rev](/clients/clash-verge-rev/) 或 [FlClash](/clients/flclash/) 时，首要工作是用正则过滤潜在高倍率节点，并将 Gemini 隔离到日/新/美节点组（按厂商“视节点而定”口径）：

```yaml
proxy-groups:
  - name: "暮光-主力低延迟"
    type: url-test
    url: "https://www.gstatic.com/generate_204"
    interval: 180
    tolerance: 50
    include-all: true
    filter: "(?i)(香港|HK|台湾|TW|日本|JP|新加坡|SG)"
    exclude-filter: "(?i)(2x|3x|5x|倍率|专线测试)"

  - name: "暮光-AI与流媒体分流"
    type: select
    include-all: true
    # 避开香港节点，将 AI 请求锁定在新/日/美节点
    filter: "(?i)(新加坡|SG|日本|JP|美国|US)"
    exclude-filter: "(?i)(2x|3x|5x|倍率)"

rules:
  - DOMAIN-SUFFIX,openai.com,暮光-AI与流媒体分流
  - DOMAIN-SUFFIX,chatgpt.com,暮光-AI与流媒体分流
  - DOMAIN-SUFFIX,gemini.google.com,暮光-AI与流媒体分流
  - DOMAIN-SUFFIX,claude.ai,暮光-AI与流媒体分流
  - MATCH,暮光-主力低延迟
```

2. **情况 B：若后台仅提供封闭式自研客户端**
   则 OpenWrt 软路由与上述 YAML 规则均无法使用。此时应在桌面端采用 **Chrome 独立工作 Profile** 隔离 AI 会话 Cookie、关闭浏览器 WebRTC 泄漏，并自行检查系统代理模式下的本地 DNS 解析是否走远端（参见 [DNS 防泄漏指南](/tutorials/dns/)）。

## 7. 常见问题（FAQ）

### 暮光加速最低真的是 9 元一个月吗？

不是按月单买 9 元。“9 元/月起”是年付轻量版 `¥109/年`（70GB/月）折算后的月均价（约 `¥9.08/月`）。按月购买的最低档位是基础版 `¥20/月（120GB）`。

### 暮光加速适合直接买 529 元或 959 元不限时包吗？

不建议首单直接购买。一来其不限时包单 GB 成本高达 `¥1.20–¥1.46/GB`（显著高于光速云 ¥0.595/GB 与星岛梦 1TB 包 ¥0.60/GB）；二来暮光目前零独立实测、协议与流量倍率均未透明，缺乏长期锁仓的安全垫。

### 暮光加速能用于 OpenWrt 软路由或 Clash 吗？

目前属于 `待核实` 状态。品牌资料未明确说明是否提供 Clash/Mihomo/Shadowrocket 通用订阅链接，也未披露协议名称。有软路由需求的用户购买前应先向客服确认是否支持订阅导出，或优先选择明确支持第三方订阅的竞品。
