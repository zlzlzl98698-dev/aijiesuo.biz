## 3. 专属客户端局限与网络层替代工程方案

飞猫云主打 **专属客户端免配置（`proprietary_only`）**，这意味着它直接阻断了三项进阶工程能力：**1）无法在 OpenWrt 软路由（OpenClash / Nikki / PassWall2）上为全家设备做透明代理；2）无法导入 Mihomo / Clash 编写精细的“ChatGPT 走美国、Gemini 走新加坡、香港走直连海外”分流策略组；3）无法设置 `url-test` 自动跳过失效节点。**

如果你因为省事选择了飞猫云官方 App，但又需要一定程度的 AI 防风控与系统级稳健性，建议在网络层采用以下 **三步替代工程方案**：

1. **浏览器多 Profile 隔离（替代 Clash 多地区策略组）**：在 Chrome 或 Edge 中单独建立一个 `AI-Work` 用户配置文件（Profile），仅在需要用 ChatGPT/Claude 时切换专属 App 至对应的美国/新加坡节点，并在该 Profile 内安装 WebRTC 控制策略（禁用真实内网/公网 UDP IP 泄漏）。切忌在同一个浏览器会话里频繁在“香港—美国—日本”节点间来回切换后直接刷新 AI 页面。
2. **本地 DNS 与代理模式校验**：使用专属 App 时，优先测试其虚拟网卡（TUN）模式与系统代理模式下的 DNS 出口；若采用系统代理模式，建议在隔离浏览器内开启安全的 DoH（DNS-over-HTTPS）并关闭本地直连 IPv6，避免国内 ISP DNS 抢先解析或泄漏真实归属地（排查方法见 [DNS 泄漏排查](/troubleshooting/dns/)）。
3. **冷备通用客户端并行（不冲突切换原则）**：若后续发现专属 App 无法满足复杂开发需求（如终端 `git`/`pip`/Docker 代理或软路由需求），可在电脑端保留一个 **Clash Verge Rev / FlClash** 并搭配小额永久包作冷备。**注意绝对不要同时开启两个客户端的 TUN 虚拟网卡模式**，切换时先完全退出飞猫云客户端再启动备用客户端。

## 7. 常见问题（FAQ）

### 飞猫云不用配置订阅，底层到底用的是什么协议？

虽然面向普通用户的专属客户端隐藏了配置流程，但 `2026-08-11 08:52:30 CST` 的 `MAI-TEST-BOT` 实测截图显示其节点采用 **Shadowsocks** 协议。不过普通用户通常无法直接在官网面板按通用机场方式自行管理分流规则，具体是否能向客服申请兼容订阅需现场核实。

### 飞猫云学生版 84 元/年能用优惠码 flycat888 打 8 折吗？

原始资料仅在完整数据表中记录 `flycat888` 为 8 折，未明示是否排除学生年付版或一次性不限时套餐。建议购买前先在官网结算页试填优惠码核对实付金额，切勿默认年付必定折上折。

### 飞猫云能稳定看晚高峰 4K 或刷 Claude/ChatGPT 吗？

目前无法做出保证。品牌资料坦承其定位是轻快日常连接而非顶级专线，且唯一实测截图拍摄于早间 `08:52`（非晚高峰），也不含 AI/流媒体检测列。建议先买一个月 **¥25 星耀版（150GB）** 在本地宽带晚高峰自测。
