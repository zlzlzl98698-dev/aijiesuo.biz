# 微风网络（BreezeNet）深度评测：50 节点 IEPL+VLESS 实测与异常节点剔除指南

在 2023 年上线的中等规模 IEPL 机场中，**微风网络（`weifeng`，英文名 BreezeNet）** 最鲜明的特点是**宣传协议与实测协议完全吻合**：品牌资料注明 `IEPL 专线 + VLESS`，而入库实测截图同样显示为 `50/50 Vless` 节点。不过，它的核查档案里也同时存在两项必须交代清楚的细节：第一，实测图片虽归档于 `2026-08-11` 目录，图内底部实标测试时间为 **`2026-07-19 18:38:20 CST`**；第二，该次实测跑出了极高香港带宽，但也明确抓到了两个不可用/极慢异常节点。当前研究评分为 **`69/100`**。

## 1. 核心判断（协议透明与坏点处理）

- **协议一致且傍晚前段带宽亮眼** `[实测证据 Measured]`：`2026-07-19 18:38:20 CST` 珠海联通 `9Gbps 32 线程` 实测中，50 个 Vless 节点香港 01–15 均速达到 `468–546MB/s`（`FullCone`），新加坡 `135–401MB/s`，日本多数 `79–257MB/s`。
- **必须配置自动剔除异常节点** `[实测证据 Measured]`：同张截图真实记录了 **`台湾02`（0.00B）与 `日本05`（8.00KB）** 的失效/极慢异常，如果客户端开全局手动死绑单个节点，遇到坏点会直接断流。
- **入门价格三重口径澄清** `[文档冲突]`：不要误信基础数据行残留的“年付约 7 元/月 50GB”；完整套餐表最低为 **清风 `¥137/年`（100GB/月，折约 `¥11.42/月`）**，常规月付最低为 **乘风 `¥27/月`（200GB/月）**。
- **尚未验证项** `[待核实]`：缺乏 8 月及以后近况复测、缺乏 AI/流媒体独立检测列，且流量倍率、设备同时在线上限与支付方式未披露。

## 4. 客户端与防异常节点分流工程（Mihomo / Clash 配置）

品牌文本未限制专属客户端，且 MiaoKo 可直接拉取其 `Vless` 订阅，建议搭配支持 Mihomo/Xray 内核的 [Clash Verge Rev](/clients/clash-verge-rev/)、[v2rayN](/clients/v2rayn/)、[Shadowrocket](/clients/shadowrocket/) 或软路由 [OpenClash](/clients/openclash/)。

针对微风网络在 `2026-07-19` 实测中暴露出的 **`台湾02（0.00B）` 与 `日本05（8.00KB）` 异常节点**，工程上必须用 **`url-test` 定时健康测速 + `fallback` 兜底组**，让客户端自动剔除零吞吐或超时节点，同时把 AI 请求隔离到美国/新加坡/日本（规避香港风控）：

```yaml
proxy-groups:
  - name: "微风-自动优选(跳过死节点)"
    type: url-test
    url: "https://www.gstatic.com/generate_204"
    interval: 120
    timeout: 2000
    tolerance: 50
    lazy: true
    include-all: true
    # 自动剔除高延迟与异常测试点，主跑香港/新加坡/日本
    filter: "(?i)(香港|HK|新加坡|SG|日本|JP|台湾|TW)"
    exclude-filter: "(?i)(台湾02|TW02|日本05|JP05|倍率|到期|剩余)"

  - name: "微风-Fallback兜底"
    type: fallback
    url: "https://www.gstatic.com/generate_204"
    interval: 180
    timeout: 2500
    proxies:
      - "微风-自动优选(跳过死节点)"
    include-all: true
    filter: "(?i)(香港|HK|新加坡|SG|日本|JP)"

  - name: "微风-AI分流(美新日)"
    type: url-test
    url: "https://chat.openai.com/favicon.ico"
    interval: 300
    timeout: 3000
    include-all: true
    filter: "(?i)(新加坡|SG|日本|JP|美国|US)"
    exclude-filter: "(?i)(日本05|JP05|倍率)"

rules:
  - DOMAIN-SUFFIX,openai.com,微风-AI分流(美新日)
  - DOMAIN-SUFFIX,chatgpt.com,微风-AI分流(美新日)
  - DOMAIN-SUFFIX,claude.ai,微风-AI分流(美新日)
  - DOMAIN-SUFFIX,gemini.google.com,微风-AI分流(美新日)
  - MATCH,微风-Fallback兜底
```

> [!TIP]
> 若在使用中发现某个地区全部节点超时，可参考 [节点超时排查指南](/troubleshooting/timeout/) 将 `timeout` 放宽至 `3000ms` 并检查本地是否开启了冲突的透明代理。

## 7. 常见问题（FAQ）

### 微风网络真的有 7 元一个月的套餐吗？

目前在完整套餐表中不存在 7 元/月（¥84/年 50GB）的在售档位，最低为年付 `清风 ¥137/年`（100GB/月，折约 `¥11.42/月`），常规月付最低为 `乘风 ¥27/月`（200GB/月）。“7 元/月”应为早期摘要残留，下单前请以官网实时定价页为准。

### 微风网络 7 月实测里的 0.00B 和 8.00KB 节点影响大吗？

如果不开自动测速、手动死绑单个故障节点就会断连；但微风总共有 50 个 Vless 节点，同批实测香港 01–15 均速达 `468–546MB/s`。只要在 Mihomo / Clash 中配置本文给出的 `url-test + fallback` 策略组即可自动绕过异常节点。

### 微风网络能稳定解锁 ChatGPT 和 Gemini 吗？

目前尚未经过独立解锁脚本验证。品牌资料宣称原生 IP 可解锁 ChatGPT、Claude 与主流流媒体，Gemini 标注“视节点而定”；但 `2026-07-19` 截图只测了速度未测解锁，建议先购买一个月乘风（¥27）自测验证。
