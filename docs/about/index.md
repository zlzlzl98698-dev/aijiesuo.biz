## 二、独立研究评分（`Research Score` 0–100）五维计算模型

为防止商业推广合作影响技术判断，本站在底层数据结构中将 **`commercialRank`（商业参考顺位）** 与 **`researchScore`（独立研究评分，满分 100 分）** 彻底分离存储与展示。任何品牌（无论是否位于商业主推顺位）的研究评分均严格按以下 5 个可核验维度计算：

| 评分维度 | 满分权重 | 考核细则与加扣分依据 | 典型高分/低分样本举例 |
| --- | --- | --- | --- |
| **1. 资料完整度 (`completeness`)** | **30 分** | 是否具备完整的分档套餐价格表、流量周期、成立年份、设备数限制、流量倍率、支付方式与客户端说明 | 具备 7 档完整套餐表的品牌得 26–28 分；仅有一句“5.6元/月 60GB”或缺失价格表的孤本品牌仅得 8–12 分 |
| **2. 协议与线路清晰度 (`protocolLineClarity`)** | **20 分** | 是否明确标注传输协议（VLESS / Shadowsocks / Trojan / Hysteria 2）与跨境线路类型（IEPL / IPLC / BGP 中转），且与实测图协议是否一致 | 明确列出协议且实测吻合得 15–18 分；协议未标注（如榴莲云、灵猫）或宣称 VLESS 却在实测中仅见 SS 存在扣分 |
| **3. 实测证据可用性 (`measuredEvidence`)** | **25 分** | 是否留存带时间戳、测试工具与后端节点信息的原始测速或流媒体/AI 检测截图 | 光速云因同时具备 2026-08-11 测速与 2026-08-19 三网及 70 节点流媒体/AI 检测共 6 张原图得 24 分；无实测图品牌此项为 **0 分** |
| **4. 套餐与定价弹性 (`pricingFlexibility`)** | **15 分** | 是否同时提供低门槛月付试错档、轻量年付档以及一次性永久不限时流量包，满足不同频次用户需求 | 同时覆盖月付、年付、一次性永久包得 13–15 分；仅有单一周期或缺失月付表得 5–8 分 |
| **5. 风险与局限透明度 (`riskTransparency`)** | **10 分** | 官方资料是否如实说明限制条件（如“AI 解锁视节点而定”“特殊商品不支持退款”“目前缺乏统一实测数据”）且链接格式无异常 | 可信云主动声明“缺乏统一 AI/流媒体实测数据”、光速云坦承“AI 需手动切节点且特殊商品不退”得 9–10 分；链接缺少 `#` 或截图遮挡扣分 |

## 三、四级数据溯源与状态标记规范

在阅读本站任何品牌档案、测速观测台（`<SpeedTestReport />`）或解锁矩阵（`<UnlockMatrix />`）时，所有数据均被打上以下四级状态标签之一，严禁将未验证声明混同为实测结论：

1. **`实测截图来源 (Measured)`**
   - **定义**：仅指本站保留的原始测试截图直接显示的测试时间、节点名称、协议、RTT/HTTPS 延迟、吞吐速度、UDP NAT 类型以及图中可见的流媒体/OpenAI/Gemini 解锁列。
   - **硬性边界**：原始 PNG/JPG 图像作为只读证据保存，绝不裁剪时间戳或篡改图内数值（包括图中出现的 `0B`、`KB 级掉速`、`超时失败` 或 `YouTube 送中(CN)` 异常节点，均在正文与图注中如实指出）。
2. **`品牌公开资料 (Vendor Claimed)`**
   - **定义**：来自品牌方资料原文的价格、流量配额、节点数量、IEPL/IPLC 专线标注、“晚高峰不限速”或“支持 ChatGPT/Netflix”等自述信息。
   - **硬性边界**：在未获得独立多时段验证前，此类信息一律加注“品牌资料显示 / 厂商自述”，且不能直接用于证明物理专线拓扑或永久解锁能力。
3. **`历史资料参考 (Historical)`**
   - **定义**：包括 `2026-08-09` 批次归档品牌（如灵动云、浪网、边缘节点 EdgeNova）以及品牌资料附带的 `2026-10-19` 非晚高峰参考测速表。
   - **硬性边界**：历史存档品牌因存在局部截图遮挡或入口时效不确定性，本站已自动为其设置 `noindex, follow` 索引隔离，并在显著位置提醒用户勿直接大额预付。
4. **`待核实 / 存在冲突 (Unverified / Conflict)`**
   - **定义**：当不同批次资料出现前后矛盾（如轻量版月流量 `59GB` vs `69GB`、两套不同优惠码、正文称 `VLESS` 而实测图显示 `Shadowsocks`、推广链接缺少 `#` 或 `/`），本站拒绝主观猜测其中某一个数字，而是将双方来源与冲突明细完整列入“已知资料冲突与待核实清单”。

## 四、节点测速实验室采样说明与方法论局限

本站目前归档的测速证据主要包含两大批次：
- **2026-08-11 16 家机场单日节点测速批次**：多由 `MAI-TEST-BOT 2.0.0-dev`（珠海联通 5Gbps 后端，32 线程，Ping 5 次）及 `主端 4.3.3 (696) / 喵速 4.7.0 (A11-32)`（珠海联通 9Gbps 后端）完成。
- **2026-08-19 光速云多网与流媒体/AI 专项批次**（及 2026-07 微风网络、无忧链接补充快照）：使用 `MiaoKo` 自定义测试覆盖长沙电信 2Gbps、广西移动 2Gbps、河北联通 2Gbps 与珠海联通 9Gbps 单线程。

### 为什么单次测速截图不能直接决定“谁是最快机场”？
作为严谨的技术知识库，我们必须向所有读者阐明测速截图的 **5 项工程局限**：
1. **单日单点时间切片**：不同品牌在 2026-08-11 的测试时间分布在凌晨 `00:21`、早间 `08:52`、下午 `14:32` 与晚间 `22:46`。凌晨空闲期与晚高峰（`20:00–23:00`）的跨境链路负载完全不同，不可将不同时段的速度直接横向排名。
2. **单一运营商后端代表性有限**：珠海联通或长沙电信大带宽后端的吞吐上限，不代表全国各地移动家宽、校园网或鹏博士宽带用户的本地入网体验。
3. **吞吐测速不等于 AI 解锁可用性**：节点能跑出 `500Mbps` 下行带宽，只代表传输通道宽裕；但只要其落地 IP 属于香港（OpenAI/Gemini 未开放区）或机房 ASN 被 Cloudflare 拉黑，访问 ChatGPT 与 Claude 依然会报 `403` / `1020`。
4. **无法证明物理专线拓扑与长期存活**：测速工具只能观测端到端延迟与吞吐，无法通过单张图片验证服务商后端是否真实采购了 IEPL/IPLC 物理专线，更无法预测服务商未来的财务与运营稳定性。
5. **因此本站的唯一选型建议是**：将测速截图作为“排除虚假空壳与观察节点池规模”的初筛证据，**首次购买任何品牌均坚持从 ¥19–¥25 月付档或百元内小额包开始**，在你自己的家庭宽带晚高峰完成实测验证。

## 六、常见问题（FAQ）

### 1. 为什么有些品牌在本站能搜到档案，却在侧边栏和 Sitemap 里看不到？
对于属于 `2026-08-09` 历史存档且存在截图遮挡的品牌（如灵动云、浪网、边缘节点 EdgeNova），或仅有单张测速图而缺失全部官方套餐与入口资料的品牌（如快狸），为了保护读者免受过期信息误导并集中搜索引擎抓取预算，本站自动为其注入了 `noindex, follow` 标签并从侧边栏与 XML Sitemap 中移出。读者仍可在 [机场品牌总库](/brands/) 中检索并查看其历史核查记录。

### 2. 如果发现某家品牌的最新官网价格、协议或优惠码与本站记录不符，如何反馈？
本站已建立自动化数据审计队列（参见工程目录 `data/verification-queue.md` 與 《AI解锁第一阶段数据交叉核验报告》），定期复核双优惠码冲突、链接格式异常与协议变动。随着新一轮三网晚高峰实测批次完成，我们将持续更新 本站品牌参数核验数据库 中的 `verifiedAt` 核实时间戳与实测图集。
