# 订阅拉取与更新失败（Timeout / 403）排查与修复

::: tip 核心结论（Answer-First）
更新订阅失败时，最先要改变的操作习惯是：**分清“不走代理直接拉取”与“通过可用节点拉取”**。如果旧节点已全部过期，客户端又勾选了“通过代理更新”，请求就会陷入死循环；反之若机场域名本身被本地宽带屏蔽，直接拉取会 Timeout，此时需开启一个临时可用节点再选“通过代理更新”，或从官网获取最新备用订阅域名。
:::

## 1. 故障表现

- 在 Clash Verge Rev、FlClash、v2rayN 或 Shadowrocket 中点击更新订阅，弹窗提示 `Timeout`、`403 Forbidden`、`502 Bad Gateway`、`invalid yaml`、`EOF` 或节点列表更新后变成空白。
- 点击机场后台“一键导入”没有反应，或者导入后提示无法识别配置文件格式。

## 2. 可能原因

1. **更新路由环路（“先有鸡还是先有蛋”）**：本地节点已经失效断网，但客户端设置里仍开启了“使用代理更新订阅”，导致订阅请求发往一个已经死掉的本地端口。
2. **订阅域名在本地运营商网络无法直连**：部分机场主域名或订阅下发域在特定省份宽带下遭遇 DNS 污染或 HTTPS 阻断。
3. **Cloudflare WAF / 面板 UA 拦截（报 403）**：部分机场后端禁止浏览器直接打开，或只放行带有特定 `User-Agent`（如 `Clash.Meta`、`ClashVerge`、`Shadowrocket`）的客户端请求；过老或偏门客户端容易被误杀返回 `403`。
4. **格式不匹配**：把通用 Base64 订阅直接塞进只认 Clash YAML 的软件，或把 Clash YAML 链接塞进只认 Base64 的老版 v2rayNG（以及复制时多带了换行符、中文提示文字）。
5. **机场官网域名更换或服务停运**：老域名已废弃，或服务商已停止运营（可参考[跑路与停运风险识别](/risk/shutdown/)核对失联征兆）。

## 3. 诊断顺序

1. **核对链接本身是否纯净**：把订阅链接粘贴进纯文本记事本，确认以 `http://` 或 `https://` 开头，中间无空格、末尾无中文汉字。
2. **用命令测试真实 HTTP 状态码**：在终端模拟客户端 UA 请求订阅接口，一眼分辨是 `Timeout`（网络被阻断）、`403`（UA/WAF 拦截）、还是 `404/401`（Token 失效或域名弃用）。
3. **切换“直连更新” vs “代理更新”**：根据上一步结果决定是否需要暂时关闭系统代理进行直连拉取，或借助手机流量/备用节点走代理更新。

## 4. 修复步骤

### 步骤 1：在客户端切换订阅更新的代理策略
- **情况 A（旧节点全挂但机场订阅域在国内可直连）**：确保关闭或绕过当前失效代理。在 Clash Verge Rev 右键该订阅 → 设置/编辑 → **取消勾选“使用系统代理更新 / Use Proxy”**；在 v2rayN 中点击“更新订阅（**不通过代理**）”。
- **情况 B（机场订阅域名本身在本地宽带被墙）**：切换到能连通的手机 4G/5G 热点，或先启用一个仍可用的备用节点，勾选**“通过代理更新”**完成拉取。

### 步骤 2：修正 User-Agent 与订阅格式参数
- 若报 `403` 或返回 HTML 验证页而非节点内容：在客户端订阅设置中尝试将自定义 `User-Agent` 改为标准值（如 `clash-verge/v2.0` 或 `ClashMeta`）；或登录机场后台重新点击“重置订阅链接”（防止旧 Token 泄密被风控封停）。
- 若提示 YAML 解析错误：核对机场后台按钮，确保 Clash 系客户端复制的是“Clash 订阅”，而 v2rayNG 复制的是“通用/V2Ray 订阅”，不要混用；或改用支持多格式兼容的 [Hiddify](/clients/hiddify/) / [Karing](/clients/karing/)。

### 步骤 3：核查最新防失联地址或备用订阅域
- 登录服务商最新发布的发布页/官网（注意防范钓鱼站），查看是否更换了专门用于国内拉取的**CDN 订阅备用域名**，重新复制新地址覆盖导入。

## 5. 验证结果

使用终端命令直接模拟客户端拉取一次响应头和字节大小，快速验明订阅源健康度（替换为你自己的真实订阅 URL，切勿对外公开展示你的 Token）：

```bash
# 测试模拟 Clash 客户端请求头的返回状态码与数据体大小
curl -s -o /dev/null -A "clash-verge/v2.0" -w "http_code=%{http_code} size=%{size_download} bytes\n" "https://你的订阅域名/subscribe?token=你的TOKEN"
```

- **正常标准**：返回 `http_code=200` 且 `size` 通常在数千到数十万字节以上；此时回到客户端即可正常刷新出完整节点列表。

## 6. 进一步处理

- 如果机场在后台直接删除了第三方订阅通道并切换为**纯专属客户端模式**（例如部分品牌仅支持账号登录，可参考 [飞猫云品牌档案](/brands/feimao/) 与 [无忧链接品牌档案](/brands/wuyou/) 的客户端模式说明），即使链接格式正确也无法再拉取，需前往官网下载其专属软件。
- 若希望兼顾第三方通用订阅与自研客户端备份，可查看 [光速云品牌档案](/brands/guangsu/)；若当前服务商在多地多网均无法访问且长期无公告更新，应警惕[跑路与停运风险](/risk/shutdown/)，并通过 [月付低沉没成本方案](/pricing/monthly/) 或 [2026 机场推荐](/airport/recommend/) 筛选具备实测证据的替代品牌。
