## 横向对比的四条基本原则

1. **不在不同测试时间窗口下硬排“速度第一”**：例如光速云的 `2026-08-11` 图测于 `14:32:56 CST`，星岛梦测于凌晨 `01:48:13 CST`，飞猫云测于早间 `08:52:30 CST`，两者公网背景负载不同，因此对比重点放在**证据覆盖面、协议透明度与异常节点风险**。
2. **明确标注价格口径陷阱**：不少品牌宣传“约 7–8 元/月”，实际对应的是**年付一次性付清的小流量包**（例如 79–109 元/年、每月 40–70GB），若选择按月付费，起步价普遍在 **19–25 元/月**。对比页会同时列出年付折算与纯月付门槛。
3. **区分“宣传支持 AI”与“分地区实测结果”**：除光速云具备 `2026-08-19` 三网与单线程 OpenAI/Gemini 实测表外，其余对比品牌（如暮光加速、飞猫云、星岛梦、极连云、光年梯）的 AI 解锁目前仅停留在 `vendor_claimed`（厂商自述）或 `untested`（未测）层级。
4. **把资料冲突直接摆在台面上**：无论是暮光加速的优惠码矛盾、飞猫云专属端与 MAI-TEST-BOT 测速之间的技术疑问，还是云界线/环球梯推广链接缺少 `#` 的路由异常，都作为选型减分项如实披露。

## 常见问题（FAQ）

### 为什么两家机场都标 IEPL 专线，研究评分却差了 20 分以上？
研究评分不仅考察厂商自述的线路名词，还重点考核**是否具备可核查的实测测速截图、协议与套餐表格是否完整、以及是否诚实披露限制条件**。仅有文字宣传而无实测证据的品牌，研究评分会显著低于多批次实测品牌。

### 对比后还是拿不准选哪一家，最稳妥的做法是什么？
优先选择**支持通用第三方客户端（Clash / 小火箭）且提供 ¥19–¥25 月付档**的品牌，先购买单月套餐在本地宽带晚高峰（20:00–23:00）实测常用节点与 ChatGPT/Gemini 可用性，验证满意后再考虑年付或大流量包。
