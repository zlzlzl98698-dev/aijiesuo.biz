# 节点流量倍率解析：扣费原理与 1x 无倍率品牌清单

> **核心结论（Answer-First）**：看机场套餐不能只盯“每月 200GB”的标称总额，必须看清楚主力节点的**流量倍率**。`真实可用流量 = 套餐标称流量 ÷ 所用节点倍率`。如果某个套餐月流量 200GB 看似很大，但日常能稳用的香港/新加坡专线节点全是 `2x` 或 `3x` 倍率，实际你只能用 100GB 或 66GB；相反，明确承诺 **1x（无倍率）** 的套餐则能做到消费多少扣多少，计费最透明。

## 流量倍率的计算机制与常见档位含义

机场面板后台（如常见的 SS/V2Ray/Xray 计费后端）会对每一个落地节点配置一个 `traffic_rate`（流量倍率系数）。统计周期内你的实际扣费量按以下公式计算：

$$\text{面板扣费流量} = (\text{上行传输字节} + \text{下行传输字节}) \times \text{节点倍率系数}$$

| 节点后缀 / 倍率标识 | 含义与后台扣费效果（以真实传输 10GB 为例） | 服务商设置该倍率的常见目的 |
| --- | --- | --- |
| **`0.5x`（低倍率）** | 仅扣除 **5GB** 套餐流量 | 引导用户分流到成本极低的普通公网直连节点、冷门欧美地区或带宽充裕的普通中转机 |
| **`1x` / `1.0x`（标准无倍率）** | 扣除 **10GB** 套餐流量（1:1 真实扣除） | 透明计费基准，最容易核算单 GB 真实成本，不会在月底突然“莫名其妙流量见底” |
| **`1.5x` / `2x`（中高倍率）** | 扣除 **15GB / 20GB** 套餐流量 | 常用于高成本 IEPL/IPLC 物理专线节点或优质流媒体/AI 解锁专用落地机，抑制大流量下载党占满专线 |
| **`3x` / `5x`+（极高倍率）** | 扣除 **30GB / 50GB** 套餐流量 | 稀缺小众地区、独享级别原生住宅 IP 或高防定制专线出口；极其不适合用来看 4K 视频或下载大文件 |

> **关键细节**：别忽略**上行（上传）流量同样乘以倍率**！例如你在云盘同步备份 10GB 照片或跑大文件上传时，经过 `2x` 节点依然会扣除 `20GB` 配额。

## 买后 2 分钟自查：如何核实任何机场的真实节点倍率

如果你购买了一家“未标注倍率”的机场，或者想验证标称 1x 的节点是否名副其实，可按以下步骤核查：

1. **查看订阅导入后的节点名称**：绝大多数主流面板会在节点末尾自动拼接倍率后缀，例如 `香港 IEPL 01 [1.5x]`、`新加坡原生 [2x]` 或 `美国直连 [0.5x]`。如果没有标注，不要轻易假设全都是 `1x`。
2. **用 100MB 测试文件做面板实测对照**：
   - 先记录机场后台网页显示的“当前剩余流量”（精确到 MB）；
   - 在客户端选中单一待测节点，下载一个已知大小约 100MB 的海外测试文件（避免同时有其他软件在后台跑大流量）；
   - 等待 3–5 分钟待后台统计刷新后，对比已用流量的增量：若增加了约 `100MB` 即为 `1x`；若增加了 `200MB` 或 `300MB`，说明后台存在 `2x`/`3x` 隐性扣费规则。
3. **检查客户端“自动测速优选组”有没有误连高倍率节点**：
   - 在 Clash 配置文件中，如果 `自动选择 (URL-Test)` 把所有节点混在一起，一旦某条 `3x` 节点碰巧延迟最低，你的后台流量就会在不知不觉中以 3 倍速度蒸发。强烈建议在策略组或规则里排除高倍率节点名称关键字（如正则过滤 `2x|3x|5x`）。

## 减少无谓流量消耗的 3 个工程习惯

1. **严格运行在 `Rule` 规则模式**：确保国内视频网站（B站/爱奇艺/抖音）、国内网盘、国内软件更新走 `DIRECT` 直连。
2. **排查系统后台静默同步**：Windows 11 更新包、Steam 游戏跨区更新、iCloud 照片全量备份和 OneDrive 同步一旦不小心走了代理，哪怕 `1x` 倍率也能在一晚吃掉 50GB。可通过[代理分流规则教程](/tutorials/routing/)将 `microsoft`、`steamcontent` 等大文件 CDN 域名显式设为直连。
3. **关闭高频测速插件**：部分浏览器预加载插件或客户端把自动测速间隔设得过短（如 10 秒一次）且测试地址文件过大，也会制造无效消耗。

## 常见问题（FAQ）

### 有 `2x` 或 `3x` 倍率的机场一定就是坑人的吗？
**不是**。公开透明标明倍率的机场，其本质是“差异化定价”：日常刷网页用 `1x` 或 `0.5x` 节点省流量，关键时刻开会或解锁稀缺服务才切去 `2x` 专线节点。真正坑的是**售前完全不提倍率、导入后发现所有能连上的节点全标 3x/5x**，或者面板根本不标明后缀却暗地按多倍扣费。

### 为什么不限时永久流量包用户更应该关注倍率？
因为[不限时永久流量包](/pricing/non-expiring/)是按总 GB 买断的（单 GB 成本约 ¥0.60–¥1.00），如果误连 `3x` 倍率节点看 4K 视频，相当于把单 GB 使用成本直接拉高到 ¥1.80–¥3.00，非常不划算。因此购买不限时包时应重点核查 1x 倍率承诺。

### `0.5x` 倍率的节点能用来日常主力吗？
可以作为下载大文件、看普通海外长视频的省流量出口，但要注意 `0.5x` 节点往往是低成本直连或非优化线路，在晚高峰出现卡顿或被 AI 风控的概率更高。
